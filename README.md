# Personal Portfolio Website

This is a **responsive and visually appealing personal portfolio website** built using only **HTML and CSS**. It showcases my web development skills, design aesthetics, and ability to create clean, modern UIs without relying on JavaScript frameworks.

## ✨ Features

- Smooth scroll navigation
- Animated hero section
- Responsive layout (mobile, tablet, desktop)
- About section with circular profile image
- Project cards with hover effects
- Skills section with animated progress bars
- Contact form (frontend only)
- Sticky glass-effect navigation bar
- Clean, accessible, and semantic HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Google Fonts
